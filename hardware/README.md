# Huey hardware: printed parts

Huey hardware by Leif Rydenfalk, CERN-OHL-W-2.0 (`LICENSES/CERN-OHL-W-2.0.txt`). Docs and pictures CC BY 4.0
(`LICENSES/CC-BY-4.0.txt`). Software in this kit is Apache-2.0 (`../LICENSE`, credits in `../NOTICE`).

`parts/` holds every printed part of the Huey v0.3.1 kit as STEP, at the exact version that is printed. Open them in
any CAD tool (FreeCAD, Fusion, Onshape) to change them or export STL for slicing.

Every part was drawn from scratch, from our own numbers: the robot's joint frames, the Feetech HD-1910 servo
datasheet, caliper measurements of the bought parts (servos, board, cells, screws) and our other parts. No upstream
mesh was imported, traced or measured.
